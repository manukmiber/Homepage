# Logo Zeiko — versi Windows 95

Tanda Zeiko (jaring, pilar, dua kelelawar) digambar ulang sebagai ikon piksel, dengan nama "Zeiko" dalam
huruf bitmap tebal. Semua digambar untuk Zeiko; tidak ada logo, ikon atau nama Windows/Microsoft di
dalamnya. `overview.png` menampilkan semuanya sekaligus.

| File | Untuk |
|---|---|
| `zeiko-mark-*` | Ikon 32×32 (gelap). Profil, avatar, ikon aplikasi. |
| `zeiko-mark-day-*` | Ikon 32×32 versi terang (latar putih). |
| `zeiko-mark-16-*` | Ikon 16×16, untuk ukuran sangat kecil (favicon, tab, tombol Start). |
| `zeiko-wordmark-black-*`, `-white-*` | Nama "Zeiko" saja. |
| `zeiko-logo-horizontal-*` | Ikon + nama, untuk latar terang. |
| `zeiko-logo-horizontal-on-dark-*` | Ikon + nama, untuk latar gelap. |
| `zeiko-desktop-icon-*` | Ikon di desktop teal dengan label terpilih. Cocok untuk post persegi. |
| `zeiko-titlebar-*` | Title bar jendela dengan nama Zeiko. Cocok untuk banner. |
| `zeiko-start-button-*` | Tombol Start Zeiko. |

Setiap gambar ada sebagai SVG (tajam di ukuran berapa pun) dan PNG di beberapa ukuran.

## Aturan pakai

- **Perbesar hanya dengan kelipatan bulat** (2×, 4×, 8×, 16×…) dan tanpa penghalusan
  ("nearest neighbour"), supaya pikselnya tetap kotak tajam. SVG aman di ukuran berapa pun.
- Di bawah 32 piksel, pakai versi 16×16.
- Beri ruang kosong di sekeliling logo, minimal seperempat lebar ikonnya.
- Jangan ganti warnanya. Pilih versi gelap atau terang sesuai latar.
