Documents, sheets & text

Write a Word document, work on a spreadsheet, fix a config file or look inside a ZIP, in Drive.

On this page

  • Documents
  • Spreadsheets
  • Text & code
  • ZIP files

Documents

For Word documents (.docx) and new documents. The toolbar has text styles and headings, bold, italic, underline, strikethrough, highlight, alignment, bulleted and numbered lists, checklists, quotes, links, pictures, tables (rows, columns, merge and split cells) and a dividing line.

  • A .docx opens as its text, headings, lists, tables and pictures. Page layout, headers and footers, comments and tracked changes are left out, and the editor says so when it opens the file; replacing the original keeps the old one in Trash.
  • Save writes a .docx. Save as… also offers Markdown and HTML.
  • Word documents also open in a preview, without the editor.

Spreadsheets

For Excel files (.xlsx), CSV and TSV, and new spreadsheets: formulas, number formats (currency, percent, decimals), merged cells, frozen rows and columns, sorting, filters, comments, links, and several sheets. Right-click a cell or a row or column header for more.

  • Save keeps the file's own format; Save as… offers Excel (.xlsx) or CSV.
  • A CSV holds one sheet, so only the sheet you have open is saved. Its separator (comma, semicolon or tab) is kept, and values such as phone numbers starting with 0 stay as you typed them.
  • Old .xls files are not supported; save them as .xlsx first.

Text & code

For notes, Markdown, code and config files. The editor colours the code by its language (from the file name), numbers the lines, and has Find & replace and Wrap long lines. Markdown files have a Preview.

Files must be UTF-8 text; the editor keeps their line endings (Windows or not). The bar at the bottom shows the line and column you are on.

ZIP files

Open the ZIP shows its folders and files without unpacking anything.

  • Press the download button beside a file to get just that one.
  • Tick files or folders and unpack only those, or press Unpack to Drive for everything: it goes into a new folder named after the ZIP, next to it, with its folders kept.
  • Password-protected files are marked and skipped. Every file is checked as it comes out, so a damaged one is skipped and named, never saved broken.
  • The leftovers other computers add (__MACOSX, .DS_Store, Thumbs.db) are not shown and not unpacked.
