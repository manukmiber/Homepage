Files & folders

Everything you can do with files in Drive, button by button. New to Drive? Start with Drive basics.

On this page

Making folders and files

Press New in the folder you want:

  • New folder makes an empty folder (it starts as Untitled folder; type its name).
  • Upload files and Upload a folder pick from your device. A folder keeps the folders inside it.
  • Document, Spreadsheet and Text file open an empty file in its editor. When you save, it goes into the folder you are in. See Documents, sheets & text.

On a computer you can also drag files from your desktop onto the page: Drive says where they will go (Drop to upload to …).

The uploads panel

While files go up, a panel at the bottom shows each one with its speed and the time left.

What it saysWhat it means
WaitingIt starts as soon as one of the files ahead of it is done. A few files go up at the same time.
Retrying…The connection hiccuped. Drive tries again by itself.
Finishing…Everything is up; Drive is putting the file together.
PausedYou pressed Pause. Resume carries on from there.
Failed / Cancelled / SkippedIt did not go up. Clear removes finished rows from the panel.
  • The page closed halfway? Next time you open Drive it asks whether to pick up where it stopped: Resume or Start over.
  • Name already taken? Choose Replace, Keep both or Skip; tick Do this for all to answer once for every file.
  • Out of space? The upload stops and offers Get more space. See Drive plans.

Views and sorting

Switch between Grid view (thumbnails) and List view (rows with Modified and Size). Sort by Name, Date modified, Size or Type. A long folder shows the first files and a Load more button.

Selecting several

  • Computer: click a file to select it, Ctrl-click (⌘ on a Mac) to add or remove one, Shift-click to select everything in between. Ctrl+A selects the whole folder.
  • Phone: press and hold a file, then tap the others.

The bar at the top says how many are selected and offers what works for all of them: download (several files come as one archive), share, move, star, move to Trash. Clear selection (or Esc) lets go.

Moving and copying

  • Move to… opens your folders: go into the one you want and press Move here.
  • Make a copy puts a copy next to the original.
  • Or use the keyboard: Ctrl+C (copy) or Ctrl+X (cut), open the folder you want, then Ctrl+V.

Every action also has a short Undo on the message that appears after it.

The file menu

Right-click a file, or press its ⋮, for everything you can do with it. What shows depends on the file:

ItemWhat it does
Open / PreviewOpens a folder, or shows the file.
DownloadSaves it to your device.
ShareMakes a link. See Sharing & downloads.
Rename, Make a copy, Move to…As above.
Edit photo, Edit video, PDF tools, Make a PDF, Edit document, Edit spreadsheet, Edit text, Open the ZIPOpens the file in its editor. See Tools & editors.
Star / Remove starPuts it in Starred, or takes it out.
DetailsType, location, owner, when it was made and changed, its safety check, and whether it is in your personal or family space.
Move to TrashDeletes it, with a way back (below).

Previews

Photos, videos, audio, PDFs, text and code, and Word documents open in a preview. Use the arrows (or ← →) to go to the previous or next file, and Esc to close. The preview's Edit opens the file's editor. For other kinds of files the preview says there is none yet; download them instead.

Keyboard shortcuts

KeysWhat they do
EnterOpen the selected file or folder
F2Rename it
Delete or BackspaceMove the selection to Trash
Ctrl+ASelect everything in the folder
Ctrl+C, Ctrl+X, Ctrl+VCopy, cut, paste
Arrow keysMove between files
EscClear the selection, close a preview or a menu

On a Mac, ⌘ works where Ctrl is written.

Trash in detail

  • Move to Trash takes files out of their folder; they still count towards your space until they are deleted for good.
  • In Trash, Restore puts a file back where it was, and Delete forever removes it at once. This cannot be undone.
  • Empty Trash deletes everything in it for good. Trash says how many days a file stays before that happens by itself.
