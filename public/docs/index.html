Two kinds of model

Pranata V1A decision model. Ask yes or no, pick one, or score it, and get a probability for every option. Yours as soon as you have an account. Roleplay modelsJagad, Asmarandana and Wisanggeni: 256K context, streaming, three content ratings. Keys on request.

They are separate products with separate prices: Pranata V1 has plans of its own, and the roleplay models are priced per token. One API serves both.

Quickstart: Pranata V1

  1. Create an accountCreate a Zeiko Account with your email, or with a one-click sign-in.
  2. Confirm your emailType the 6-digit code we send into the banner on your account page, or open the link in the email.
  3. Buy a plan or add balanceOn Plans & balance. Plans start at $1 for 30 days; past a plan, calls come out of your balance.
  4. Copy your keyOn API key, press Show key, then Copy. The address that goes with it is on the same page.
  5. Ask your first questionKeep the key in an environment variable, ZEIKO_API_KEY here, and send:
curl
curl https://ai.zeiko.biz.id/v1/decisions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pranata-v1",
    "state": "Thanks so much! The order came a day early and works perfectly.",
    "questions": {
      "positive": {
        "type": "noul",
        "instructions": "Is this review positive?"
      }
    }
  }'

The answer is the probability that the answer is yes:

Answer
{
  "model": "pranata-v1",
  "answers": {
    "positive": { "type": "noul", "noul": 0.97 }
  },
  "usage": { "input_tokens": 24, "output_tokens": 0 }
}

Every field, the two other kinds of question and the errors are in the Decisions API. No code yet? Try Pranata V1 in the playground first: 5 free tries every 30 minutes.

Quickstart: roleplay models

  1. Ask for a keyEmail admin@zeiko.biz.id with the models you want and roughly what volume you expect.
  2. Get your keyIt arrives with everything you need to connect.
  3. Send a chat requestAny official OpenAI SDK works: give it the base URL below and your key. Or send it yourself:
curl
curl https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jagad-512b-v1",
    "messages": [
      {"role": "system", "content": "You are Aria, a cheerful barista in a rainy harbour town."},
      {"role": "user", "content": "*shakes off my umbrella* One hot chocolate, please."}
    ]
  }'

Parameters, streaming and the reply's fields are in the Chat API.

The API at a glance
Base URLhttps://ai.zeiko.biz.id/v1
KeyAuthorization: Bearer YOUR_API_KEY on every request
FormatJSON over HTTPS; chat replies can stream as server-sent events
Pranata V1POST /v1/decisions
Roleplay modelsPOST /v1/chat/completions
Model listGET /v1/models, no key needed

Zeiko Drive

Zeiko Drive keeps your files on the same Zeiko Account: upload at full speed, share with a link, download many files at once. It has no API of its own; you use it in the app at drive.zeiko.biz.id.
