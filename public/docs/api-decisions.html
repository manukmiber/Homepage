Decisions API

Ask Pranata V1 one or more questions about a text or a JSON object, and get a probability for every option.

On this page

  • A complete example
  • The request
  • The response
  • Limits
  • Errors
  • Examples

POSThttps://ai.zeiko.biz.id/v1/decisions

A complete example

Three questions, one of each kind, about the same reply:

curl
curl https://ai.zeiko.biz.id/v1/decisions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pranata-v1",
    "state": "Aria: *slides a steaming mug across the counter* Extra marshmallows, on the house. Rain like this calls for it.",
    "questions": {
      "in_character": {
        "type": "noul",
        "instructions": "Does the reply stay in character as Aria, a cheerful barista?",
        "criteria": {
          "true": "It sounds like Aria and stays in the scene",
          "false": "It breaks character or talks about being an AI"
        }
      },
      "mood": {
        "type": "choice",
        "instructions": "Which mood fits the next scene?",
        "criteria": {
          "calm": null,
          "tense": "Danger or conflict is close",
          "playful": null
        }
      },
      "warmth": {
        "type": "score",
        "instructions": "How warm is the reply towards the customer?",
        "criteria": ["Cold", "Polite", "Friendly", "Warm", "Very warm"]
      }
    }
  }'

The answer (the figures are illustrative):

Answer

The request

FieldTypeNotes
modelstringRequired. pranata-v1.
statestring, object, array or nullRequired. What is being judged: plain text, or JSON when it has parts, such as a conversation or a form. null when there is nothing to read.
questionsobjectRequired. 1 to 256 questions, each under an id you choose. The same ids come back as the keys of answers.

A question

FieldTypeNotes
typestringRequired. noul (yes or no), choice (pick one) or score (score it).
instructionsstring, object or arrayThe question itself, such as “Does this reply stay in character?”. Optional, but almost always wanted.
criteriadepends on the typeWhat the answers mean. See below.

criteria, by type

TypeWhat it takes
noulOptional. An object with "true" and/or "false", each describing that answer.
{"true": "The reply sounds like the character", "false": "It breaks character"}
choiceRequired. An object of 2 to 255 options: each option's name, then a description of it, or null for none. The names come back in the answer.
{"calm": null, "tense": "Danger or conflict is close", "playful": null}
scoreRequired. An array of 2 to 10 levels, lowest first. Each level is a description, or null.
["Not urgent", "Low", "Medium", "High", "Drop everything"]

A description can be plain text, or an object or an array when that says it better, for example a description with a few examples of it.

Question ids

The ids are yours: short names such as in_character or mood. They label the answers and are not priced; the model reads the instructions and the criteria, not the id.

The response

FieldTypeNotes
modelstringThe model you asked.
answersobjectOne answer per question, under the question's id.
usage.input_tokensintegerThe tokens in the state and the questions: what the call is priced on.
usage.output_tokensintegerAlways 0: answers are not priced.

The request's id is in the X-Request-Id header.

Answers, by type

TypeFieldNotes
noulnoulThe probability of yes (true), from 0 to 1. No is 1 minus it.
choicechoiceThe option that fits best. On a tie, the one written first.
choiceprobabilitiesEvery option with its probability. They add up to 1.
choiceconfidence0 when the probabilities are even, 1 when one option has them all.
scorescoreThe weighted average of the level positions: from 0 (the first level) to the number of levels minus 1. It can fall between levels.
scorelegendEach position, "0" up, with its level exactly as you wrote it.
scoreprobabilitiesEach position with its probability. They add up to 1.
scoreconfidenceFrom 0 to 1; higher when the probability sits close around the most likely level.

Every answer also has its type. Probabilities have up to six decimal places. Fields may be added later: ignore any you do not use.

Limits
Longest call2,048 tokens: the state, and every question's instructions and criteria
Questions per callUp to 256, within the 2,048 tokens
Options per choice2 to 255
Levels per score2 to 10
One plan request1,024 tokens: a call of 1,025 to 2,048 tokens counts as two

A call over 2,048 tokens is refused with 422 before anything is used. Split the state, or ask a long question in a call of its own.

Errors

The error body has two extras here: param names the field that was wrong, and detail repeats the message.

Error
{
  "error": {
    "message": "question \"mood\": a choice needs at least two options",
    "type": "invalid_request_error",
    "code": "invalid_request",
    "param": "questions.mood.criteria"
  },
  "detail": "question \"mood\": a choice needs at least two options"
}
StatusCodeWhen
400wrong_endpointYou sent a roleplay model. Send it to /v1/chat/completions.
401invalid_api_keyThe key is missing or unknown.
402insufficient_balanceNo plan covers the call, and it costs more than your balance.
403invalid_api_keyThe key is turned off.
403no_planThe key has nothing to call with right now. Buy a plan or add balance.
403plan_expiredYour plan has ended, and your balance does not cover the call.
403model_forbiddenThe key may not call that model.
404model_not_foundNo model has that ID. IDs are lowercase.
422invalid_requestThe body is not right, or the call is too long. param names the field.
429plan_limit_reachedThis period's plan requests are used, and your balance does not cover the call.
429rate_limit_exceededYour key's per-second, per-minute or daily limit.
429model_busyA great many calls at once. Wait, then send it again.
502model_unavailableThe model could not answer. Retry with backoff.

Every 429 carries Retry-After (seconds) and retry-after-ms (milliseconds). Treat any other 429 code the same way.

Examples

Python

Python
import os
import requests

API = "https://ai.zeiko.biz.id/v1"
KEY = os.environ["ZEIKO_API_KEY"]

def decide(state, questions):
    r = requests.post(
        API + "/decisions",
        headers={"Authorization": "Bearer " + KEY},
        json={"model": "pranata-v1", "state": state, "questions": questions},
        timeout=30,
    )
    if r.status_code == 429:
        raise RuntimeError("busy, retry in %s s" % r.headers.get("Retry-After"))
    r.raise_for_status()
    return r.json()["answers"]

answers = decide(
    "Can someone call me back today? The heating is off and it is freezing.",
    {
        "urgency": {
            "type": "score",
            "instructions": "How urgent is this message?",
            "criteria": ["Not urgent", "Low", "Medium", "High", "Drop everything"],
        },
        "team": {
            "type": "choice",
            "instructions": "Which team should take this message?",
            "criteria": {
                "repairs": "Something is broken",
                "accounts": "Questions about money",
                "other": None,
            },
        },
    },
)
print(answers["urgency"]["score"], answers["team"]["choice"])

JavaScript (Node 18 or newer)

JavaScript
const res = await fetch("https://ai.zeiko.biz.id/v1/decisions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.ZEIKO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "pranata-v1",
    state: "Can someone call me back today? The heating is off and it is freezing.",
    questions: {
      needs_reply: { type: "noul", instructions: "Does this message need a reply today?" },
    },
  }),
});
if (!res.ok) {
  const err = await res.json().catch(() => null);
  throw new Error(res.status + " " + (err?.error?.code ?? "") + ": " + (err?.error?.message ?? ""));
}
const { answers, usage } = await res.json();
console.log(answers.needs_reply.noul, usage.input_tokens);

A JSON state, several questions

When the thing being judged has parts, send it as an object and name its fields in your questions:

Request body
{
  "model": "pranata-v1",
  "state": {
    "title": "Handmade ceramic mug, 350 ml",
    "description": "Glazed by hand. Dishwasher safe. Ships in 2 days.",
    "photos": 3
  },
  "questions": {
    "complete": {
      "type": "noul",
      "instructions": "Does the description say what the item is made of, its size and when it ships?"
    },
    "category": {
      "type": "choice",
      "instructions": "Which category does the listing belong in?",
      "criteria": { "kitchen": null, "home_decor": null, "gifts": null, "other": "None of the others fit" }
    },
    "quality": {
      "type": "score",
      "instructions": "How useful is the description to a buyer?",
      "criteria": ["Useless", "Poor", "Fine", "Good", "Excellent"]
    }
  }
}
