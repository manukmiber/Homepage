Three kinds of decision

Yes or no noul

A straight answer to a straight question, and how sure it is. The answer is the probability of yes, from 0 to 1. You can say what yes and no mean in your case.

For example: “Does this reply stay in character?” “Is this message spam?” “Does the review ask for a refund?”

Pick one choice

List the options, 2 to 255, with a short description of each if you like. The answer names the option that fits best, gives every option its probability, and adds a confidence from 0 (an even split) to 1 (all of it on one option).

For example: “Which mood fits the next scene?” “Which team should take this ticket?” “What language is this text in?”

Score it score

Give a scale of 2 to 10 levels, lowest first. The answer gives every level its probability, a score (the weighted average of the level positions, 0 for the first level), and a confidence that is high when the probability sits close around one level.

For example: “How urgent is this message, from 1 to 5?” “How closely does this text follow the brief?” “How formal is this email?”

How a call works

  1. State: the thing being judged. A message, a conversation, a product listing: plain text, or a JSON object or array when it has parts.
  2. Questions: one or more, each under an id you choose, with its kind, the question itself (instructions) and what the answers mean (criteria).
  3. Answers: one per question, under the same id, each with its probabilities.

Several questions about the same state go in one call. The whole call, the state and every question together, can be up to 2,048 tokens. The format is in the Decisions API reference.

Writing good questions

  • Keep the state to what matters. Detail that has nothing to do with the question only gets in the way, and every token counts toward the call's length and price.
  • Ask one thing per question. “Is it rude and off-topic?” is two questions: ask both, separately, in the same call.
  • Name the part you mean. If the state is an object, refer to its fields by name: “Is latest_message a question?”
  • Say what each answer means. A one-line description of yes and no, or of each option, sharpens the answer more than a longer question does. A short example of each helps most.
  • Write levels from lowest to highest, each one clearly apart from its neighbours.
  • Cover every case. If none of the options may fit, add one for that, such as other.

Using the answer

  • Set your own threshold. Act on a yes only above the probability your use needs: 0.5 for an easy call, 0.8 or 0.9 for something that is hard to undo.
  • Use the confidence. For Pick one and Score it, a low confidence means the text does not settle the question. Send those to a person, or ask a sharper question.
  • A score can fall between levels. 2.75 on a five-level scale leans on the fourth level (position 3) with some weight below it. Round it, or work from the probabilities.
