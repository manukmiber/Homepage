Chat API

The roleplay models use the chat completions format the OpenAI SDKs speak: messages in, a reply out, streamed or all at once.

On this page

  • A complete example

POSThttps://ai.zeiko.biz.id/v1/chat/completions

A complete example

curl
curl https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jagad-512b-v1",
    "messages": [
      {"role": "system", "content": "You are Aria, a cheerful barista in a rainy harbour town."},
      {"role": "user", "content": "*shakes off my umbrella* One hot chocolate, please."}
    ],
    "stream": false,
    "max_tokens": 1024,
    "temperature": 0.9,
    "reasoning_effort": "low",
    "user": "user-9f3c1ab7"
  }'

The reply:

Request parameters

ParameterNotes
modelRequired. jagad-512b-v1, asmarandana-512b-v1 or wisanggeni-512b-v1.
messagesRequired. The conversation, oldest first. Each item is {"role", "content"}: role is system, user or assistant, and content is a string.
streamtrue for a stream of events (below), false for one JSON reply. Defaults to false.
max_tokens
max_completion_tokens		The longest reply you want, in tokens, up to 32,000.
temperature
top_p		Sampling, as in the OpenAI API. Each model has its own defaults when you leave them out.
stopA string, or an array of strings: the reply stops before any of them. Only the first four are used.
reasoning_effortnone, minimal, low, medium, high or max: how much the model thinks before it answers, and so which output rate applies. high when you send none. reasoning: {"effort": "…"} works too.
include_reasoningfalse leaves the reasoning text out of the reply; reasoning: {"exclude": true} does the same. It is still produced, and counted in usage.
userRecommended. A stable, anonymous id for the person the request is for. user_id works too. More below.

The user field

If one key serves many people, send each person's id as user. It helps repeated input be read from cache, at the cache-read rate (see usage.prompt_tokens_details.cached_tokens). Make it:

  • Stable: the same person always gets the same id.
  • Unique: two people never share one.
  • Anonymous: a hash or an account number; never an email address, a phone number or a name. At most 120 characters.

Leaving it out works too; every request on the key is then treated as coming from one person.

The reply

FieldTypeNotes
idstringThe request's id, also sent as the X-Request-Id header. Keep it if you may write to us about the request.
objectstring"chat.completion"
createdintegerUnix time, in seconds.
modelstringThe model ID you sent.
choices[0].message.contentstringThe reply.
choices[0].message.reasoning_contentstringThe model's reasoning, when there is any and you did not leave it out. Some replies call this field reasoning: read whichever is there.
choices[0].finish_reasonstringstop when the reply finished, length when it reached max_tokens.

Usage

FieldTypeNotes
usage.prompt_tokensintegerInput tokens: the messages you sent.
usage.completion_tokensintegerOutput tokens, reasoning included.
usage.total_tokensintegerThe two added up.
usage.prompt_tokens_details.cached_tokensintegerHow much of the input was read from cache. Left out when zero.
usage.completion_tokens_details.reasoning_tokensintegerHow much of the output was reasoning. Left out when zero.
usage.costnumberWhat this request cost, in USD, to up to nine decimal places.

Headers

HeaderValue
Content-Typeapplication/json, or text/event-stream; charset=utf-8 when streaming.
X-Request-IdThe same value as id.
Retry-AfterSeconds to wait before trying again, on some 429 replies.

Replies may carry fields that are not listed here. Ignore any you do not know.

Streaming

With "stream": true the reply is text/event-stream: one data: line per chunk, then a chunk with usage, then data: [DONE].

Stream
data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"role":"assistant","content":""},"finish_reason":null}]}

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"content":"*slides a steaming"},"finish_reason":null}]}

: keep-alive

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"content":" mug across the counter*"},"finish_reason":"stop"}]}

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[],"usage":{"prompt_tokens":42,"completion_tokens":310,"total_tokens":352,"cost":0.0004717}}

data: [DONE]
LineWhat to do with it
Content chunksAppend each choices[0].delta.content, in order. The first chunk carries role and usually no text. Reasoning, when included, arrives as delta.reasoning_content (or delta.reasoning).
Lines starting with :Comments that keep the connection open while the model works. Ignore them; never parse them as JSON.
The usage chunkThe chunk with usage. Its choices is usually empty, but it can carry the last piece of text: check that choices[0] exists before reading it.
An error chunkIf something fails after the stream has started, a chunk {"error": {"message", "type", "code"}} comes before [DONE]. The status stays 200: it was sent before the error happened.
data: [DONE]The end of the stream. It is not JSON.
  • id, created and model are the same on every chunk of one reply.
  • One chunk can arrive split across several reads. Buffer until a blank line (\n\n or \r\n\r\n) before parsing.
  • Turn off response buffering in your HTTP client; with curl, use -N.
  • Disconnecting in the middle stops the reply. What was produced until then still counts.

Refusals

The roleplay models are for roleplay and the writing around it. Other requests, such as code, homework or general questions, get a short refusal: an ordinary reply (HTTP 200, finish_reason: "stop") that costs a flat $0.05 in place of its token price, shown in usage.cost. Retrying it with the same request gets the same answer.

Errors

StatusCodeWhen
400(none)The request has no model.
400invalid_requestThe model did not accept the request, for example a parameter value it does not take.
400wrong_endpointYou sent Pranata V1. Send it to /v1/decisions.
401invalid_api_keyThe key is missing or unknown.
403invalid_api_keyThe key is turned off.
403model_forbiddenYour key may not call that model.
404model_not_foundNo model has that ID. IDs are lowercase.
404(none)No such path; type is not_found.
413context_length_exceededThe input is longer than the model's context. It is never cut short to fit: the request is refused.
413too_largeThe request is too large for this model.
429rate_limit_exceededYour key's per-minute limit or daily quota, or the model is busy. The per-minute case carries Retry-After.
429overloadedFull for the moment. Carries Retry-After.
500internal_errorAn unexpected error.
502model_unavailableThe model could not answer.
504timeoutThe model took too long to answer.

Three errors are plain text, not JSON: a body that is not valid JSON (400), a missing Content-Type: application/json header (415), and a body over the size limit (413). Check an error's Content-Type before parsing it. When to retry: API basics.

Examples

curl, streaming

curl
curl -N https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \

    "model": "jagad-512b-v1",

Python (OpenAI SDK), one reply

Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.zeiko.biz.id/v1",
    api_key=os.environ["ZEIKO_API_KEY"],
)

reply = client.chat.completions.create(
    model="jagad-512b-v1",
    messages=[{"role": "user", "content": "*waves* Hi there!"}],
    reasoning_effort="low",
    user="user-9f3c1ab7",
)
print(reply.id)
print(reply.choices[0].message.content)
print(reply.usage.prompt_tokens, reply.usage.completion_tokens)
print(reply.usage.model_extra.get("cost"))

Python (OpenAI SDK), streaming

Python
stream = client.chat.completions.create(
    model="jagad-512b-v1",
    messages=[{"role": "user", "content": "*waves* Hi there!"}],
    user="user-9f3c1ab7",
    stream=True,
)
usage = None
for chunk in stream:
    if chunk.usage is not None:  # the usage chunk
        usage = chunk.usage
    if chunk.choices:  # never assume choices[0] is there
        piece = chunk.choices[0].delta.content
        if piece:
            print(piece, end="", flush=True)
print("\n", usage)

JavaScript (OpenAI SDK), streaming

JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.zeiko.biz.id/v1",
  apiKey: process.env.ZEIKO_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "jagad-512b-v1",
  messages: [{ role: "user", content: "*waves* Hi there!" }],
  user: "user-9f3c1ab7",
  stream: true,
});
for await (const chunk of stream) {
  const piece = chunk.choices[0]?.delta?.content;
  if (piece) process.stdout.write(piece);
  if (chunk.usage) console.log("\ntokens:", chunk.usage.total_tokens);
}

JavaScript (fetch), streaming

JavaScript
const res = await fetch("https://ai.zeiko.biz.id/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.ZEIKO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "jagad-512b-v1",
    messages: [{ role: "user", content: "*waves* Hi there!" }],
    user: "user-9f3c1ab7",
    stream: true,
  }),
});
const reader = res.body.getReader();
const decoder = new TextDecoder();
let buf = "";
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });
  // An event ends with a blank line; take CRLF too.
  let m;
  while ((m = /\r?\n\r?\n/.exec(buf)) !== null) {
    const event = buf.slice(0, m.index);
    buf = buf.slice(m.index + m[0].length);
    for (const line of event.split(/\r?\n/)) {
      if (!line.startsWith("data:")) continue; // ": keep-alive" too
      const data = line.slice(5).trim();
      if (data === "[DONE]") continue; // the end, not JSON
      const json = JSON.parse(data);
      if (json.error) { console.error(json.error.message); continue; }
      const piece = json.choices?.[0]?.delta?.content;
      if (piece) process.stdout.write(piece);
      if (json.usage) console.log("\ncost:", json.usage.cost);
    }
  }
}
