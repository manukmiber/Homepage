Staging, Git, cron & PHP

The tools behind a site that keeps changing: a copy of WordPress to try things on, deploying from a Git repository, jobs that run on a clock, and the PHP version and settings your site runs with. All of them are in cPanel; sign in first (how).

On this page

  • A staging copy of WordPress
  • Deploy from Git
  • Cron jobs
  • PHP version and settings

A staging copy of WordPress

A staging copy is a second WordPress, with the same posts, theme and plugins, where you can update or change things without your visitors seeing it. When it looks right, you push it to the live site.

  1. Open your installationsIn cPanel, open Softaculous Apps Installer, then All Installations (the boxes icon at the top).
  2. Make the copyBeside your WordPress, press the Create Staging icon. Choose a folder such as staging, so the copy opens at yourdomain.com/staging, and press Create Staging.
  3. Work on itSign in to the copy at yourdomain.com/staging/wp-login.php with the same username and password. Update plugins, change the theme, try what you like.
  4. Push it liveBack in All Installations, the copy has a Push to Live icon. Choose what to push (files, the database, or both) and press Push to Live. Softaculous backs up the live site first.

The copy uses your plan’s space and a database of its own. Delete it from All Installations when you are done.

Deploy from Git

cPanel keeps a copy of your repository and can put its files into your site each time you update it.

  1. Let cPanel read a private repositorySkip this for a public one. Open SSH Access, Manage SSH Keys, Generate a New Key, and leave the passphrase empty. Open the new public key with View/Download and add it to your repository as a read-only deploy key.
  2. Clone itOpen Git Version Control and press Create. Paste the repository’s clone address (for a private one, the SSH address, like git@github.com:you/site.git), choose a folder outside public_html, such as repositories/site, and press Create.
  3. Say where its files goAdd a file named .cpanel.yml to the top of the repository, like the one below, with your cPanel username in it. Commit and push it.
  4. DeployIn Git Version Control, press Manage on the repository, open Pull or Deploy, press Update from Remote, then Deploy HEAD Commit.
.cpanel.yml
---
deployment:
  tasks:
    - export DEPLOYPATH=/home/USERNAME/public_html/
    - /bin/cp -R index.html css js img $DEPLOYPATH

List the files and folders your site needs after cp -R. A repository without .cpanel.yml is cloned and updated, but nothing is deployed.

Cron jobs

A cron job runs a command on a clock: a nightly cleanup, a newsletter, a report.

  1. Open Cron JobsIn cPanel, open Cron Jobs.
  2. Pick whenUnder Add New Cron Job, choose from Common Settings (once an hour, once a day…) or type the minute, hour, day, month and weekday yourself. Times are the server’s.
  3. Type the commandRun PHP with its full path, like the first line below, with your cPanel username in it. Press Add New Cron Job.
command
/usr/local/bin/php /home/USERNAME/public_html/cron.php
cd /home/USERNAME/public_html && /usr/local/bin/php wp-cron.php >/dev/null 2>&1

The second line runs WordPress’s own scheduled tasks on the clock instead of on page visits. Use it every 15 minutes, and add define('DISABLE_WP_CRON', true); to wp-config.php. Run a job at most every 5 minutes. Whatever a job prints is emailed to the address under Cron Email; end the command with >/dev/null 2>&1 to get no email.

PHP version and settings

  1. Pick the versionIn cPanel, open MultiPHP Manager (or Select PHP Version, if that is the one your cPanel shows). Tick your domain, choose the PHP version and press Apply. Each domain can have its own.
  2. Change a settingOpen MultiPHP INI Editor, choose your domain, and change what you need, such as upload_max_filesize, post_max_size, memory_limit or max_execution_time. Press Apply.

Check that your site works after a change of version: a plugin or theme that is too old for a newer PHP shows an error or a blank page. Switch back the same way if it does. A setting cannot go past what your plan gives, such as its RAM.
