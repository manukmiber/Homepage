Tools & editors

Drive can edit your files right in the browser: photos, videos, PDFs, Word documents, spreadsheets, text and code, and ZIP files. Nothing to install, and your file stays on your device while you work.

On this page

  • Opening an editor
  • Which editor for which file
  • Saving your work
  • Good to know

Opening an editor

  • A file in your Drive: open its menu (⋮ or right-click) and choose the editor, such as Edit photo or PDF tools, or press Edit in its preview.
  • A file on your device: open Tools in Drive's menu and press Choose from this device on the editor you want.
  • A new file: New → Document, Spreadsheet or Text file, or New empty file in Tools.

Which editor for which file

FilesEditorWhat it does
Photos (JPEG, PNG, WebP…)Photo editorLooks, tune, curves, details, healing, lens blur, text, frames, crop, straighten, size
VideosVideo editorTrim, split, delete or reorder parts, join several videos
PDFs, and photos into a PDFPDF toolsFill & sign, forms, pages, watermark, page numbers, compress, pictures, text
Word documents (.docx)DocumentHeadings, lists, checklists, tables, pictures, links
Excel and CSVSpreadsheetFormulas, number formats, merged cells, sorting, filters, several sheets
Text, Markdown, codeText & codeFind & replace, line wrap, Markdown preview
ZIPZIPLook inside, download one file, unpack into Drive

Saving your work

Every editor ends the same way: press Save, and Save the result offers

  • Save as a new file: next to the original, with “(edited)” in its name, which you can change;
  • Replace the original: the edited file takes its place, and the original moves to Trash, so it can still be restored;
  • Download to this device: nothing goes to Drive.

The size before and after is shown, so you see what the edit did. Closing an editor with changes not saved asks first: Keep editing or Discard changes.

Good to know

  • Your file stays with you. Editing happens in your browser; see Safety & privacy.
  • Size limits. Each editor takes files up to a size that a phone can handle; a bigger file gets a message saying the limit.
  • Phones work. Every editor is laid out for a phone screen as well as a computer.
  • Undo. The photo, PDF and video editors, documents and spreadsheets all have undo.
