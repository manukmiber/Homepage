Put your site online

Sign in to cPanel, then install WordPress, upload your own files, or start an app. On your own domain, point it here first (Connect your domain) so you can see the result at it; an address under zeiko.biz.id is ready already.

Sign in to cPanel

Open the cPanel address from your welcome email and sign in with your username and password. If the page stops loading after a few wrong passwords, your connection has been blocked for a while: write to admin@zeiko.biz.id with your IP address and we lift it.

WordPress in one click

  1. Open SoftaculousIn cPanel, open Softaculous Apps Installer and choose WordPress.
  2. Press InstallChoose https:// and your domain, and leave In Directory empty so the site opens at the domain itself.
  3. Name itFill in the site’s name, and the WordPress username, password and email you will sign in with. Write them down.
  4. InstallPress Install and wait a minute. Softaculous shows the link for signing in to WordPress.

Softaculous makes the site’s database for you, and installs other apps the same way.

Upload your own site

Your main domain’s files go in the public_html folder; each domain you add gets the folder you chose for it. The page that opens first is index.html or index.php.

  • File Manager: open public_html, press Upload, and upload your files, or one ZIP of them; then right-click the ZIP and choose Extract.
  • FTP: FTP Accounts in cPanel makes a sign-in for an FTP app such as FileZilla. Connect to your domain, or the IP address in your welcome email, on port 21.
  • Git: clone your repository over SSH into the folder.

Databases

  1. Make a databaseIn cPanel, open MySQL Databases and create one. Its full name starts with your cPanel username, like username_shop.
  2. Make a userOn the same page, add a user with a strong password.
  3. Give the user the databaseUnder Add User To Database, pick both, press Add, and tick ALL PRIVILEGES.
  4. Put it in your site’s settingsHost localhost, the database’s full name, the user’s full name, and its password.

To bring in a database you already have, open phpMyAdmin, choose the database on the left, and use Import with your .sql file.

Node.js apps

  1. Upload your codeInto a folder of its own outside public_html, for example myapp, without node_modules.
  2. Create the appIn cPanel, open Setup Node.js App and press Create Application. Pick the Node.js version, set Application root to your folder, Application URL to the domain it answers at, and Application startup file to your entry file, such as app.js. Press Create.
  3. Install the packagesPress Run NPM Install: it reads your package.json.
  4. Restart after each changePress Restart on the app’s page whenever you upload new code.

Have your app listen on process.env.PORT; it is started for you.

Python apps

  1. Create the appIn cPanel, open Setup Python App and press Create Application. Pick the Python version, the Application root folder and the Application URL, keep the startup file as passenger_wsgi.py, and press Create.
  2. Upload your codeInto that folder. passenger_wsgi.py hands your app over as application: for Flask, from app import app as application; for Django, the application from your project’s wsgi.py.
  3. Install the packagesAdd requirements.txt under Configuration files and press Run Pip Install. Or, in the Terminal, run the command shown at the top of the app’s page, then pip install -r requirements.txt.
  4. Restart after each changePress Restart.

Ruby apps

  1. Create the appIn cPanel, open Setup Ruby App, pick the Ruby version, the Application root folder and the Application URL, and create it.
  2. Upload your codeInto that folder, with a config.ru that starts your app. Rails and Sinatra apps have one.
  3. Install the gemsIn the Terminal, run the command shown on the app’s page, then bundle install.
  4. Restart after each changePress Restart.

SSH and Terminal

Terminal in cPanel opens a shell in your browser. To connect from your own computer, open SSH Access, then Manage SSH Keys: import your public key and authorize it. Then connect with your cPanel username to your domain, or the IP address in your welcome email, on the SSH port it gives.

The shell is jailed: it sees your own files and nobody else’s. git, npm, pip and bundle work there.

Email on your domain

In cPanel, open Email Accounts and press Create to make an address like you@yourdomain.com. Read it in webmail at yourdomain.com/webmail, or in any mail app with the settings Connect Devices shows beside the address. It works once your domain uses way 1.
