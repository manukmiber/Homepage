Which band applies?

none and minimal land in the no-thinking band; low, medium and high in the standard band; max in the max-thinking band. Reasoning tokens count as output tokens at the band's output rate.

Refusals

A model that refuses still had to read the prompt first, so it is not free — but it is not billed as a full answer either: $0.05 flat per request, replacing the token count.

Billing

Usage is summarised into an invoice per period: per-model breakdown, subtotal, tax, total. Paid in USDT (TRC20), with the IDR rate printed on the invoice.

Get started

Your base URL and API key arrive together when the key is issued. Everything after that is an ordinary OpenAI call.

chat completion, streaming 
curl https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Asmarandana-512B-V1",
    "messages": [
      {"role": "system", "content": "You are a patient listener."},
      {"role": "user",   "content": "Retell my day, but make it heroic."}
    ],
    "reasoning_effort": "none",
    "stream": true
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.zeiko.biz.id/v1/chat/completions",
    api_key="sk-zeiko-...",
)

stream = client.chat.completions.create(
    model="Jagad-512B-V1",
    messages=[{"role": "user", "content": "Hi, tell me who you are."}],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.zeiko.biz.id/v1/chat/completions",

FAQ

Do I have to change my client code?

No. The endpoints, the request shape and the response shape follow OpenAI, so the official SDKs and most third-party clients only need a new base_url and API key.

How is the cost worked out?

Per token, per million tokens, following the table above — with the band chosen by the reasoning_effort on your request. Input, cache-read, output and reasoning tokens are recorded separately on every usage line.

What is the difference between a company and a private key?

A company key stands in front of many end users: every call carries its own user id, and that id is what appears on the invoice breakdown. A private key is a single holder — the user field is ignored, and responses are never paced.

If a model refuses, am I still billed?

Yes, but at $0.05 flat for that request rather than the price of a full answer. A refusal is recognised from the spoken answer itself; reasoning blocks are not counted.

What gets stored?

Usage metrics needed for billing and diagnostics — counts, timings, status — plus a short preview of the prompt and answer. Nothing is sold or shared.
