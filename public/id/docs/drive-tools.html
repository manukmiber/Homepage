Alat & editor

Drive bisa mengedit file-mu langsung di browser: foto, video, PDF, dokumen Word, spreadsheet, teks dan kode, serta file ZIP. Tidak perlu memasang apa pun, dan file-mu tetap di perangkatmu selama kamu bekerja.

Di halaman ini

  • Membuka editor
  • Editor untuk tiap file
  • Menyimpan hasil
  • Perlu diketahui

Membuka editor

  • File di Drive-mu: buka menunya (⋮ atau klik kanan) lalu pilih editornya, misalnya Edit foto atau Alat PDF, atau tekan Edit di pratinjaunya.
  • File di perangkatmu: buka Alat di menu Drive lalu tekan Pilih dari perangkat di editor yang kamu mau.
  • File baru: Baru → Dokumen, Spreadsheet, atau File teks, atau Buat file kosong di Alat.

Menyimpan hasil

Semua editor berakhir dengan cara yang sama: tekan Simpan, lalu Simpan hasil menawarkan

  • Simpan sebagai file baru: di sebelah aslinya, dengan “(edit)” di namanya, yang bisa kamu ubah;
  • Ganti file asli: file hasil edit menggantikannya, dan aslinya dipindah ke Sampah, jadi masih bisa dipulihkan;
  • Unduh ke perangkat: tidak ada yang masuk ke Drive.

Ukuran sebelum dan sesudah ditampilkan, jadi kamu tahu efek editannya. Menutup editor dengan perubahan yang belum disimpan selalu bertanya dulu: Lanjut edit atau Buang perubahan.

Perlu diketahui

  • File-mu tetap bersamamu. Proses edit terjadi di browsermu; lihat Keamanan & privasi.
  • Batas ukuran. Setiap editor menerima file sampai ukuran yang sanggup diolah HP; file yang lebih besar mendapat pesan yang menyebutkan batasnya.
  • Jalan di HP. Setiap editor ditata untuk layar HP maupun komputer.
  • Urungkan. Editor foto, PDF, dan video, dokumen, dan spreadsheet semuanya bisa diurungkan.
