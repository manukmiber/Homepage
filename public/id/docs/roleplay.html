Model roleplay

Tiga model untuk roleplay dan penulisan kreatif, dari aman untuk umum sampai tanpa batasan. Konteks sama, panjang balasan sama, API sama: yang berbeda adalah apa yang mau mereka katakan, dan harganya.

Tingkat berpikir

Setiap permintaan bisa mengatur seberapa keras model berpikir sebelum menjawab, dengan reasoning_effort. Kalau tidak diisi, model berpikir di tingkat high. Tingkat itu menentukan tarif output:

KelompokTingkatOutput Jagad, per 1 juta token
Tanpa berpikirnone minimal$1.20
Standarlow medium high$1.50
Berpikir maksimalmax$2.00

Token penalaran dihitung sebagai token output, dengan tarif kelompoknya, jadi meminta lebih sedikit berpikir menurunkan tarif sekaligus jumlah token. Input dan cache read harganya sama di setiap tingkat. Tarif semua model ada di Harga & paket.

Untuk tidak menyertakan teks penalaran di balasan, kirim "include_reasoning": false. Penalarannya tetap dibuat, dan tetap dihitung.

Untuk apa model ini

Model roleplay dibuat untuk roleplay dan penulisan di sekitarnya. Permintaan lain, seperti kode, PR sekolah, atau pertanyaan umum, mendapat penolakan singkat. Penolakan itu datang sebagai balasan biasa (HTTP 200, finish_reason: "stop") dan harganya tetap $0.05, menggantikan harga tokennya.

Pilih yang mana?

Jagad untuk roleplay yang aman untuk umum, dan kalau kamu belum yakin. Asmarandana untuk roleplay dewasa, kalau kamu membatasi penggunamu sendiri: tawarkan hanya ke orang yang sudah kamu pastikan dewasa. Wisanggeni kalau kamu butuh model yang jarang menolak; tarifnya paling tinggi.

Performa langsung

Waktu ke token pertama, kecepatan output, latensi, dan ketersediaan setiap model, selama 24 jam, 7 hari, dan 30 hari terakhir, ada di /models, diperbarui setiap jam.

Mendapatkan kunci

Kirim email ke admin@zeiko.biz.id berisi model yang kamu mau dan perkiraan volume pemakaianmu. Kuncimu datang bersama semua yang kamu perlukan untuk tersambung; halaman API Chat menjelaskan sisanya.
