Staging, Git, cron & PHP

Alat untuk situs yang terus berubah: salinan WordPress untuk mencoba, deploy dari repositori Git, tugas yang berjalan terjadwal, serta versi dan pengaturan PHP situsmu. Semuanya ada di cPanel; masuk dulu (caranya).

Di halaman ini

  • Salinan staging WordPress
  • Deploy dari Git
  • Cron job
  • Versi dan pengaturan PHP

Salinan staging WordPress

Salinan staging adalah WordPress kedua, dengan tulisan, tema, dan plugin yang sama, tempat kamu bisa memperbarui atau mengubah sesuatu tanpa terlihat pengunjung. Kalau sudah pas, kamu dorong ke situs utama.

  1. Buka daftar instalasimuDi cPanel, buka Softaculous Apps Installer, lalu All Installations (ikon kotak-kotak di atas).
  2. Buat salinannyaDi samping WordPress-mu, tekan ikon Create Staging. Pilih folder seperti staging, supaya salinannya terbuka di domainmu.com/staging, lalu tekan Create Staging.
  3. Kerjakan di sanaMasuk ke salinannya di domainmu.com/staging/wp-login.php dengan username dan password yang sama. Perbarui plugin, ganti tema, coba apa saja.
  4. Dorong ke situs utamaKembali ke All Installations, salinannya punya ikon Push to Live. Pilih apa yang didorong (file, basis data, atau keduanya) lalu tekan Push to Live. Softaculous mencadangkan situs utama dulu.

Salinannya memakai ruang paketmu dan basis data sendiri. Hapus dari All Installations kalau sudah selesai.

Deploy dari Git

cPanel menyimpan salinan repositorimu dan bisa memasang file-nya ke situsmu setiap kali kamu memperbaruinya.

  1. Izinkan cPanel membaca repositori privatLewati untuk repositori publik. Buka SSH Access, Manage SSH Keys, Generate a New Key, dan biarkan passphrase kosong. Buka kunci publik barunya dengan View/Download lalu tambahkan ke repositorimu sebagai deploy key yang hanya bisa membaca.
  2. Clone repositorinyaBuka Git Version Control lalu tekan Create. Tempel alamat clone repositorinya (untuk yang privat, alamat SSH, misalnya git@github.com:kamu/situs.git), pilih folder di luar public_html, misalnya repositories/situs, lalu tekan Create.
  3. Tentukan ke mana file-nyaTambahkan file bernama .cpanel.yml di bagian teratas repositori, seperti di bawah, dengan username cPanel-mu. Commit dan push.
  4. DeployDi Git Version Control, tekan Manage pada repositorinya, buka Pull or Deploy, tekan Update from Remote, lalu Deploy HEAD Commit.
.cpanel.yml
---
deployment:
  tasks:
    - export DEPLOYPATH=/home/USERNAME/public_html/
    - /bin/cp -R index.html css js img $DEPLOYPATH

Tulis file dan folder yang dibutuhkan situsmu setelah cp -R. Repositori tanpa .cpanel.yml tetap di-clone dan diperbarui, tetapi tidak ada yang di-deploy.

Cron job

Cron job menjalankan perintah sesuai jadwal: pembersihan tiap malam, newsletter, laporan.

  1. Buka Cron JobsDi cPanel, buka Cron Jobs.
  2. Pilih kapanDi Add New Cron Job, pilih dari Common Settings (sejam sekali, sehari sekali…) atau ketik sendiri menit, jam, tanggal, bulan, dan hari. Waktunya mengikuti server.
  3. Ketik perintahnyaJalankan PHP dengan path lengkapnya, seperti baris pertama di bawah, dengan username cPanel-mu. Tekan Add New Cron Job.
perintah
/usr/local/bin/php /home/USERNAME/public_html/cron.php
cd /home/USERNAME/public_html && /usr/local/bin/php wp-cron.php >/dev/null 2>&1

Baris kedua menjalankan tugas terjadwal WordPress sesuai jadwal, bukan setiap ada pengunjung. Pakai setiap 15 menit, dan tambahkan define('DISABLE_WP_CRON', true); ke wp-config.php. Jalankan job paling sering 5 menit sekali. Apa pun yang ditampilkan job dikirim ke alamat di Cron Email; akhiri perintah dengan >/dev/null 2>&1 supaya tidak ada email.

Versi dan pengaturan PHP

  1. Pilih versinyaDi cPanel, buka MultiPHP Manager (atau Select PHP Version, kalau itu yang tampil di cPanel-mu). Centang domainmu, pilih versi PHP, lalu tekan Apply. Setiap domain bisa punya versi sendiri.
  2. Ubah pengaturanBuka MultiPHP INI Editor, pilih domainmu, lalu ubah yang perlu, seperti upload_max_filesize, post_max_size, memory_limit, atau max_execution_time. Tekan Apply.

Cek situsmu setelah ganti versi: plugin atau tema yang terlalu tua untuk PHP yang lebih baru menampilkan error atau halaman kosong. Kalau begitu, kembalikan dengan cara yang sama. Pengaturan tidak bisa melebihi yang diberikan paketmu, seperti RAM-nya.
