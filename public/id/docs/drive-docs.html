Dokumentasi / Alat Drive

Dokumen, spreadsheet & teks

Tulis dokumen Word, kerjakan spreadsheet, perbaiki file config, atau lihat isi ZIP, di Drive.

Di halaman ini

  • Dokumen
  • Spreadsheet
  • Teks & kode
  • File ZIP

Dokumen

Untuk dokumen Word (.docx) dan dokumen baru. Toolbarnya berisi gaya teks dan judul, tebal, miring, garis bawah, coret, stabilo, perataan, daftar berpoin dan bernomor, daftar centang, kutipan, tautan, gambar, tabel (baris, kolom, gabung dan pisah sel), dan garis pemisah.

  • File .docx terbuka sebagai teks, judul, daftar, tabel, dan gambarnya. Tata letak halaman, header dan footer, komentar, dan lacak perubahan tidak ikut, dan editor menyebutkannya saat membuka file; mengganti file asli tetap menyimpan yang lama di Sampah.
  • Simpan menulis .docx. Simpan sebagai… juga menawarkan Markdown dan HTML.
  • Dokumen Word juga bisa dibuka di pratinjau, tanpa editor.

Spreadsheet

Untuk file Excel (.xlsx), CSV dan TSV, serta spreadsheet baru: rumus, format angka (mata uang, persen, desimal), gabung sel, bekukan baris dan kolom, urutkan, filter, komentar, tautan, dan beberapa lembar. Klik kanan sel atau judul baris/kolom untuk pilihan lain.

  • Simpan mempertahankan format file-nya; Simpan sebagai… menawarkan Excel (.xlsx) atau CSV.
  • CSV hanya berisi satu lembar, jadi yang disimpan hanya lembar yang sedang dibuka. Pemisahnya (koma, titik koma, atau tab) dipertahankan, dan nilai seperti nomor HP yang diawali 0 tetap seperti yang kamu ketik.
  • File .xls lama tidak didukung; simpan dulu sebagai .xlsx.

Teks & kode

Untuk catatan, Markdown, kode, dan file config. Editor mewarnai kode sesuai bahasanya (dari nama file), memberi nomor baris, dan punya Cari & ganti serta Bungkus baris panjang. File Markdown punya Pratinjau.

File harus berupa teks UTF-8; editor mempertahankan akhir barisnya (Windows atau bukan). Bar di bawah menampilkan baris dan kolom tempat kursormu.

File ZIP

Lihat isi ZIP menampilkan folder dan file di dalamnya tanpa membongkar apa pun.

  • Tekan tombol unduh di samping file untuk mengambil file itu saja.
  • Centang file atau folder lalu bongkar yang itu saja, atau tekan Bongkar ke Drive untuk semuanya: isinya masuk ke folder baru bernama sama dengan ZIP-nya, di sebelahnya, dengan susunan foldernya.
  • File bersandi ditandai dan dilewati. Setiap file diperiksa saat dikeluarkan, jadi yang rusak dilewati dan disebutkan, tidak pernah disimpan dalam keadaan rusak.
  • Sisa-sisa dari komputer lain (__MACOSX, .DS_Store, Thumbs.db) tidak ditampilkan dan tidak ikut dibongkar.
