Dua jenis model

Pranata V1Model keputusan. Tanyakan ya atau tidak, pilih satu, atau beri skor, dan dapatkan peluang untuk setiap pilihan. Langsung bisa dipakai begitu kamu punya akun. Model roleplayJagad, Asmarandana, dan Wisanggeni: konteks 256K, streaming, tiga rating konten. Kunci diberikan atas permintaan.

Keduanya produk terpisah dengan harga terpisah: Pranata V1 punya paket sendiri, sedangkan model roleplay dihargai per token. Satu API melayani keduanya.

Mulai cepat: Pranata V1

  1. Buat akunBuat Akun Zeiko dengan email, atau dengan masuk sekali klik.
  2. Konfirmasi emailKetik kode 6 digit yang kami kirim di banner halaman akunmu, atau buka link di email itu.
  3. Beli paket atau isi saldoDi Paket & saldo. Paket mulai dari $1 untuk 30 hari; di luar paket, panggilan memakai saldomu.
  4. Salin kuncimuDi Kunci API, tekan Tampilkan kunci, lalu Salin. Alamat yang dipakai bersamanya ada di halaman yang sama.
  5. Ajukan pertanyaan pertamamuSimpan kunci di variabel lingkungan, di sini ZEIKO_API_KEY, lalu kirim:
curl
curl https://ai.zeiko.biz.id/v1/decisions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pranata-v1",
    "state": "Makasih banyak! Pesanannya datang sehari lebih cepat dan berfungsi sempurna.",
    "questions": {
      "positive": {
        "type": "noul",
        "instructions": "Apakah ulasan ini positif?"
      }
    }
  }'

Jawabannya adalah peluang bahwa jawabannya ya:

Jawaban
{
  "model": "pranata-v1",
  "answers": {
    "positive": { "type": "noul", "noul": 0.97 }
  },
  "usage": { "input_tokens": 31, "output_tokens": 0 }
}

Semua field, dua jenis pertanyaan lainnya, dan daftar error ada di API Keputusan. Belum menulis kode? Coba Pranata V1 dulu di playground: 5 percobaan gratis setiap 30 menit.

Mulai cepat: model roleplay

  1. Minta kunciKirim email ke admin@zeiko.biz.id berisi model yang kamu mau dan perkiraan volume pemakaianmu.
  2. Terima kuncimuKunci datang bersama semua yang kamu perlukan untuk tersambung.
  3. Kirim permintaan chatSDK resmi OpenAI mana pun bisa dipakai: beri base URL di bawah dan kuncimu. Atau kirim sendiri:
curl
curl https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jagad-512b-v1",
    "messages": [
      {"role": "system", "content": "Kamu Aria, barista ceria di kota pelabuhan yang sering hujan."},
      {"role": "user", "content": "*mengibaskan payung* Satu cokelat panas, ya."}
    ]
  }'

Parameter, streaming, dan field balasan ada di API Chat.

API secara singkat
Base URLhttps://ai.zeiko.biz.id/v1
KunciAuthorization: Bearer YOUR_API_KEY di setiap permintaan
FormatJSON lewat HTTPS; balasan chat bisa di-stream sebagai server-sent events
Pranata V1POST /v1/decisions
Model roleplayPOST /v1/chat/completions
Daftar modelGET /v1/models, tanpa kunci

Zeiko Drive

Zeiko Drive menyimpan file-mu di Akun Zeiko yang sama: upload dengan kecepatan penuh, bagikan lewat link, unduh banyak file sekaligus. Drive tidak punya API sendiri; kamu memakainya di aplikasi drive.zeiko.biz.id.

Dasar DriveMembuka Drive, paket pertamamu, upload, Sampah, dan datamu. Berbagi & unduhanLink share, mengirimnya, arsip, kompres, paket keluarga.
