Dasar API

Satu alamat, satu header kunci, JSON masuk dan keluar. Pranata V1 menjawab di endpoint-nya sendiri; model roleplay memakai format chat yang sudah dipakai SDK OpenAI.

Base URL

Base URL
https://ai.zeiko.biz.id/v1

Setiap path di bawah dimulai dari alamat ini. Halaman Kunci API di akunmu menampilkan alamat yang sama di samping kuncimu.

Kuncimu

Kirim kuncimu di setiap permintaan, di header Authorization:

Header
Authorization: Bearer YOUR_API_KEY
  • Kunci Pranata V1 didapat dari akunmu. Kunci model roleplay diminta lewat email.
  • Simpan kunci di servermu, di variabel lingkungan seperti ZEIKO_API_KEY, jangan pernah di kode, halaman web, atau aplikasi ponsel.
  • Kalau kunci mungkin bocor, ganti: Buat kunci baru di akunmu, atau kirim email ke kami untuk kunci roleplay. Kunci lama langsung tidak berlaku.

Endpoint

MetodePathKunciFungsinya
GET/v1/modelsTidak perluDaftar model.
GET/v1/models/{id}Tidak perluSatu model, atau 404.
POST/v1/decisionsPerluBertanya ke Pranata V1. Lihat API Keputusan.
POST/v1/chat/completionsPerluChat dengan model roleplay, di-stream atau tidak. Lihat API Chat.

Setiap model menjawab di endpoint-nya sendiri: model roleplay yang dikirim ke /v1/decisions, atau Pranata V1 yang dikirim ke /v1/chat/completions, ditolak dengan 400 wrong_endpoint sebelum ada yang terpakai.

ID ditulis huruf kecil dan harus dikirim persis seperti tertulis. GET /v1/models selalu berisi daftar terbaru, dan tidak butuh kunci:

curl
curl https://ai.zeiko.biz.id/v1/models

Setiap entri berisi id model, context_length-nya, dan harganya per token, sebagai string desimal (baca sebagai desimal, bukan float). Pakai field yang kamu perlukan dan abaikan sisanya.

Dengan SDK OpenAI

Untuk model roleplay, arahkan SDK resmi OpenAI mana pun ke base URL dan beri kuncimu:

Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.zeiko.biz.id/v1",
    api_key=os.environ["ZEIKO_API_KEY"],
)
JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.zeiko.biz.id/v1",
  apiKey: process.env.ZEIKO_API_KEY,
});

Keputusan Pranata V1 berupa JSON biasa lewat HTTPS: panggil dengan HTTP client apa pun. Contohnya ada di API Keputusan.

ID permintaan

Setiap permintaan yang dijawab membawa header X-Request-Id; balasan chat juga membawanya sebagai id. Simpan: kalau kamu menghubungi kami soal sebuah permintaan, sertakan ID itu. Untuk error, yang tidak punya ID, sertakan waktu, model, dan kode status.

Error

Error datang dengan status HTTP yang sesuai dan body JSON:

Error
{
  "error": {
    "message": "model \"jagad-512b-v2\" is not available",
    "type": "invalid_request_error",
    "code": "model_not_found"
  }
}

message ditulis untuk manusia; code yang dicek di kodemu. Setiap endpoint mencantumkan kodenya sendiri: API Keputusan, API Chat.

StatusArtinyaCoba lagi?
400 404 413 422Ada yang salah di permintaan. Perbaiki dulu.Tidak
401 403Soal kunci: tidak ada, tidak dikenal, dimatikan, atau tidak boleh memanggil model itu.Tidak
402Saldo tidak cukup untuk panggilan Pranata V1.Setelah isi saldo
429Terlalu banyak permintaan, batas tercapai, atau model sedang sibuk.Ya, setelah Retry-After
500 502 504Ada masalah di pihak kami.Ya, dua atau tiga kali

Percobaan ulang dan batas

  • 429: tunggu sebanyak detik yang disebut header Retry-After. Tanpa header itu, mundur bertahap: mulai sekitar satu detik dan gandakan setiap kali.
  • 500, 502, 504: coba lagi dua atau tiga kali, dengan jeda bertahap yang sama.
  • 4xx lainnya: jangan coba lagi. Perbaiki permintaan atau kuncinya dulu.

Sebuah kunci bisa punya batas per menit dan kuota harian; mencapai salah satunya menghasilkan 429 rate_limit_exceeded. Kalau butuh lebih, tulis ke admin@zeiko.biz.id.
