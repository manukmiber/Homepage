API Chat

Model roleplay memakai format chat completions yang dipakai SDK OpenAI: pesan masuk, balasan keluar, di-stream atau sekaligus.

POSThttps://ai.zeiko.biz.id/v1/chat/completions

Contoh lengkap

curl
curl https://ai.zeiko.biz.id/v1/chat/completions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jagad-512b-v1",
    "messages": [
      {"role": "system", "content": "You are Aria, a cheerful barista in a rainy harbour town."},
      {"role": "user", "content": "*shakes off my umbrella* One hot chocolate, please."}
    ],
    "stream": false,
    "max_tokens": 1024,
    "temperature": 0.9,
    "reasoning_effort": "low",
    "user": "user-9f3c1ab7"
  }'

Parameter permintaan

ParameterCatatan
modelWajib. jagad-512b-v1, asmarandana-512b-v1, atau wisanggeni-512b-v1.
messagesWajib. Percakapannya, dari yang paling lama. Setiap item berupa {"role", "content"}: role adalah system, user, atau assistant, dan content berupa string.
streamtrue untuk aliran event (di bawah), false untuk satu balasan JSON. Bawaannya false.
max_tokens
max_completion_tokens		Balasan terpanjang yang kamu mau, dalam token, sampai 32.000.
temperature
top_p		Sampling, seperti di API OpenAI. Setiap model punya nilai bawaan sendiri kalau tidak kamu isi.
stopString, atau array string: balasan berhenti sebelum salah satunya. Hanya empat pertama yang dipakai.
reasoning_effortnone, minimal, low, medium, high, atau max: seberapa banyak model berpikir sebelum menjawab, sehingga menentukan tarif output yang berlaku. high kalau tidak kamu kirim. reasoning: {"effort": "…"} juga bisa.
include_reasoningfalse tidak menyertakan teks penalaran di balasan; reasoning: {"exclude": true} sama saja. Penalarannya tetap dibuat, dan dihitung di usage.
userDisarankan. Id yang tetap dan anonim untuk orang yang dilayani permintaan ini. user_id juga bisa. Selengkapnya di bawah.

Field user

Kalau satu kunci melayani banyak orang, kirim id tiap orang sebagai user. Ini membantu input yang berulang dibaca dari cache, dengan tarif cache read (lihat usage.prompt_tokens_details.cached_tokens). Buat id itu:

  • Tetap: orang yang sama selalu mendapat id yang sama.
  • Unik: dua orang tidak pernah memakai id yang sama.
  • Anonim: hash atau nomor akun; jangan pernah alamat email, nomor telepon, atau nama. Maksimal 120 karakter.

Boleh juga tidak diisi; semua permintaan dengan kunci itu lalu dianggap datang dari satu orang.

Balasan

FieldTipeCatatan
idstringId permintaan, juga dikirim sebagai header X-Request-Id. Simpan kalau kamu mungkin menghubungi kami soal permintaan ini.
objectstring"chat.completion"
createdintegerWaktu Unix, dalam detik.
modelstringID model yang kamu kirim.
choices[0].message.contentstringBalasannya.
choices[0].message.reasoning_contentstringPenalaran model, kalau ada dan tidak kamu kecualikan. Sebagian balasan menamai field ini reasoning: baca yang mana pun yang ada.
choices[0].finish_reasonstringstop kalau balasan selesai, length kalau mencapai max_tokens.

Pemakaian

FieldTipeCatatan
usage.prompt_tokensintegerToken input: pesan yang kamu kirim.
usage.completion_tokensintegerToken output, termasuk penalaran.
usage.total_tokensintegerJumlah keduanya.
usage.prompt_tokens_details.cached_tokensintegerBerapa banyak input yang dibaca dari cache. Tidak muncul kalau nol.
usage.completion_tokens_details.reasoning_tokensintegerBerapa banyak output yang berupa penalaran. Tidak muncul kalau nol.

Headers

HeaderNilai
Content-Typeapplication/json, atau text/event-stream; charset=utf-8 saat streaming.
X-Request-IdNilainya sama dengan id.
Retry-AfterDetik yang harus ditunggu sebelum mencoba lagi, di sebagian balasan 429.

Balasan bisa membawa field yang tidak tercantum di sini. Abaikan yang tidak kamu kenal.

Streaming

Dengan "stream": true balasannya berupa text/event-stream: satu baris data: per potongan, lalu potongan berisi usage, lalu data: [DONE].

Stream
data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"role":"assistant","content":""},"finish_reason":null}]}

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"content":"*slides a steaming"},"finish_reason":null}]}

: keep-alive

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[{"index":0,"delta":{"content":" mug across the counter*"},"finish_reason":"stop"}]}

data: {"id":"32dadfde…","object":"chat.completion.chunk","created":1789936200,"model":"jagad-512b-v1","choices":[],"usage":{"prompt_tokens":42,"completion_tokens":310,"total_tokens":352,"cost":0.0004717}}

data: [DONE]
BarisYang harus dilakukan
Potongan isiSambung setiap choices[0].delta.content, berurutan. Potongan pertama membawa role dan biasanya tanpa teks. Penalaran, kalau disertakan, datang sebagai delta.reasoning_content (atau delta.reasoning).
Baris yang diawali :Komentar yang menjaga koneksi tetap terbuka selama model bekerja. Abaikan; jangan pernah di-parse sebagai JSON.
Potongan usagePotongan berisi usage. choices-nya biasanya kosong, tapi bisa membawa potongan teks terakhir: pastikan choices[0] ada sebelum membacanya.
Potongan errorKalau ada yang gagal setelah stream dimulai, potongan {"error": {"message", "type", "code"}} datang sebelum [DONE]. Statusnya tetap 200: status itu terkirim sebelum error terjadi.
data: [DONE]Akhir stream. Ini bukan JSON.
  • id, created, dan model sama di setiap potongan satu balasan.
  • Satu potongan bisa datang terbelah di beberapa pembacaan. Tampung sampai ada baris kosong (\n\n atau \r\n\r\n) sebelum di-parse.
  • Matikan buffering respons di HTTP client-mu; dengan curl, pakai -N.
  • Memutus koneksi di tengah jalan menghentikan balasan. Yang sudah dibuat sampai saat itu tetap dihitung.

Penolakan

Model roleplay dibuat untuk roleplay dan penulisan di sekitarnya. Permintaan lain, seperti kode, PR sekolah, atau pertanyaan umum, mendapat penolakan singkat: balasan biasa (HTTP 200, finish_reason: "stop") yang harganya tetap $0.05, menggantikan harga tokennya, dan tampil di usage.cost. Mengulang permintaan yang sama menghasilkan jawaban yang sama.

Python (SDK OpenAI), satu balasan

Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.zeiko.biz.id/v1",
    api_key=os.environ["ZEIKO_API_KEY"],
)

reply = client.chat.completions.create(
    model="jagad-512b-v1",
    messages=[{"role": "user", "content": "*waves* Hi there!"}],
    reasoning_effort="low",
    user="user-9f3c1ab7",
)
print(reply.id)
print(reply.choices[0].message.content)
print(reply.usage.prompt_tokens, reply.usage.completion_tokens)
print(reply.usage.model_extra.get("cost"))

Python (SDK OpenAI), streaming

Python
stream = client.chat.completions.create(
    model="jagad-512b-v1",
    messages=[{"role": "user", "content": "*waves* Hi there!"}],
    user="user-9f3c1ab7",
    stream=True,
)
usage = None
for chunk in stream:
    if chunk.usage is not None:  # the usage chunk
        usage = chunk.usage
    if chunk.choices:  # never assume choices[0] is there
        piece = chunk.choices[0].delta.content
        if piece:
            print(piece, end="", flush=True)
print("\n", usage)

JavaScript (SDK OpenAI), streaming

JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.zeiko.biz.id/v1",
  apiKey: process.env.ZEIKO_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "jagad-512b-v1",
  messages: [{ role: "user", content: "*waves* Hi there!" }],
  user: "user-9f3c1ab7",
  stream: true,
});
for await (const chunk of stream) {
  const piece = chunk.choices[0]?.delta?.content;
  if (piece) process.stdout.write(piece);
  if (chunk.usage) console.log("\ntokens:", chunk.usage.total_tokens);
}

JavaScript (fetch), streaming

JavaScript
const res = await fetch("https://ai.zeiko.biz.id/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.ZEIKO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "jagad-512b-v1",
    messages: [{ role: "user", content: "*waves* Hi there!" }],
    user: "user-9f3c1ab7",
    stream: true,
  }),
});
const reader = res.body.getReader();
const decoder = new TextDecoder();
let buf = "";
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });
  // An event ends with a blank line; take CRLF too.
  let m;
  while ((m = /\r?\n\r?\n/.exec(buf)) !== null) {
    const event = buf.slice(0, m.index);
    buf = buf.slice(m.index + m[0].length);
    for (const line of event.split(/\r?\n/)) {
      if (!line.startsWith("data:")) continue; // ": keep-alive" too
      const data = line.slice(5).trim();
      if (data === "[DONE]") continue; // the end, not JSON
      const json = JSON.parse(data);
      if (json.error) { console.error(json.error.message); continue; }
      const piece = json.choices?.[0]?.delta?.content;
      if (piece) process.stdout.write(piece);
      if (json.usage) console.log("\ncost:", json.usage.cost);
    }
  }
}
