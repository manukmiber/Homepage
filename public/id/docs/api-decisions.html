API Keputusan

POSThttps://ai.zeiko.biz.id/v1/decisions

Contoh lengkap

Tiga pertanyaan, satu dari setiap jenis, tentang balasan yang sama:

curl
curl https://ai.zeiko.biz.id/v1/decisions \
  -H "Authorization: Bearer $ZEIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pranata-v1",
    "state": "Aria: *slides a steaming mug across the counter* Extra marshmallows, on the house. Rain like this calls for it.",
    "questions": {
      "in_character": {
        "type": "noul",
        "instructions": "Does the reply stay in character as Aria, a cheerful barista?",
        "criteria": {
          "true": "It sounds like Aria and stays in the scene",
          "false": "It breaks character or talks about being an AI"
        }
      },
      "mood": {
        "type": "choice",
        "instructions": "Which mood fits the next scene?",
        "criteria": {
          "calm": null,
          "tense": "Danger or conflict is close",
          "playful": null
        }
      },
      "warmth": {
        "type": "score",
        "instructions": "How warm is the reply towards the customer?",
        "criteria": ["Cold", "Polite", "Friendly", "Warm", "Very warm"]
      }
    }
  }'

Jawabannya (angkanya hanya ilustrasi):

Jawaban
{

    "mood": {
      "type": "choice",
      "choice": "calm",
      "probabilities": { "calm": 0.64, "tense": 0.18, "playful": 0.18 },
      "confidence": 0.46
    },
    "warmth": {

      "probabilities": { "0": 0.03, "1": 0.07, "2": 0.22, "3": 0.48, "4": 0.2 },
      "confidence": 0.458333
    }
  },

Permintaan

FieldTipeCatatan
modelstringWajib. pranata-v1.
statestring, objek, array, atau nullWajib. Hal yang dinilai: teks biasa, atau JSON kalau punya beberapa bagian, seperti percakapan atau formulir. null kalau tidak ada yang perlu dibaca.
questionsobjekWajib. 1 sampai 256 pertanyaan, masing-masing dengan id pilihanmu. Id yang sama kembali sebagai kunci di answers.

Satu pertanyaan

FieldTipeCatatan
typestringWajib. noul (ya atau tidak), choice (pilih satu), atau score (beri skor).
instructionsstring, objek, atau arrayPertanyaannya sendiri, misalnya “Apakah balasan ini tetap sesuai karakter?”. Opsional, tapi hampir selalu diperlukan.
criteriatergantung tipenyaArti jawaban-jawabannya. Lihat di bawah.

criteria, per tipe

TipeIsinya
noulOpsional. Objek dengan "true" dan/atau "false", masing-masing menjelaskan jawaban itu.
{"true": "The reply sounds like the character", "false": "It breaks character"}
choiceWajib. Objek berisi 2 sampai 255 pilihan: nama tiap pilihan, lalu penjelasannya, atau null kalau tidak ada. Nama-nama itu kembali di jawaban.
{"calm": null, "tense": "Danger or conflict is close", "playful": null}
scoreWajib. Array berisi 2 sampai 10 tingkat, dari yang terendah. Setiap tingkat berupa penjelasan, atau null.
["Not urgent", "Low", "Medium", "High", "Drop everything"]

Penjelasan bisa berupa teks biasa, atau objek atau array kalau itu lebih jelas, misalnya penjelasan dengan beberapa contohnya.

Id pertanyaan

Id-nya kamu yang tentukan: nama pendek seperti in_character atau mood. Id hanya memberi label pada jawaban dan tidak dihitung harganya; model membaca instructions dan criteria, bukan id.

Respons

FieldTipeCatatan
modelstringModel yang kamu tanya.
answersobjekSatu jawaban per pertanyaan, dengan id pertanyaan itu.
usage.input_tokensintegerToken di state dan pertanyaan: dasar harga panggilan ini.
usage.output_tokensintegerSelalu 0: jawaban tidak dihitung harganya.

Id permintaan ada di header X-Request-Id.

Jawaban, per tipe

TipeFieldCatatan
noulnoulPeluang ya (true), dari 0 sampai 1. Tidak = 1 dikurangi angka itu.
choicechoicePilihan yang paling cocok. Kalau seri, yang ditulis lebih dulu.
choiceprobabilitiesSetiap pilihan dengan peluangnya. Jumlahnya 1.
choiceconfidence0 kalau peluangnya terbagi rata, 1 kalau satu pilihan memegang semuanya.
scorescoreRata-rata tertimbang posisi tingkat: dari 0 (tingkat pertama) sampai jumlah tingkat dikurangi 1. Bisa jatuh di antara tingkat.
scorelegendSetiap posisi, mulai "0", dengan tingkatnya persis seperti yang kamu tulis.
scoreprobabilitiesSetiap posisi dengan peluangnya. Jumlahnya 1.
scoreconfidenceDari 0 sampai 1; makin tinggi bila peluangnya berkumpul di sekitar tingkat yang paling mungkin.

Setiap jawaban juga membawa type-nya. Peluang punya sampai enam angka desimal. Field baru bisa ditambahkan nanti: abaikan yang tidak kamu pakai.

Batas
Panggilan terpanjang2.048 token: state, serta instructions dan criteria setiap pertanyaan
Pertanyaan per panggilanSampai 256, dalam batas 2.048 token
Pilihan per choice2 sampai 255
Tingkat per score2 sampai 10
Satu permintaan paket1.024 token: panggilan 1.025 sampai 2.048 token dihitung dua

Panggilan lebih dari 2.048 token ditolak dengan 422 sebelum ada yang terpakai. Pecah state-nya, atau ajukan pertanyaan panjang di panggilan tersendiri.

Error

Body error di sini punya dua tambahan: param menyebut field yang salah, dan detail mengulang pesannya.

Error
{
  "error": {
    "message": "question \"mood\": a choice needs at least two options",
    "type": "invalid_request_error",
    "code": "invalid_request",
    "param": "questions.mood.criteria"
  },
  "detail": "question \"mood\": a choice needs at least two options"
}
StatusKodeKapan
400wrong_endpointKamu mengirim model roleplay. Kirim ke /v1/chat/completions.
401invalid_api_keyKunci tidak ada atau tidak dikenal.
402insufficient_balanceTidak ada paket yang menanggung panggilan ini, dan biayanya lebih dari saldomu.
403invalid_api_keyKunci dimatikan.
403no_planKunci ini sedang tidak punya apa pun untuk memanggil. Beli paket atau isi saldo.
403plan_expiredPaketmu sudah berakhir, dan saldomu tidak cukup untuk panggilan ini.
403model_forbiddenKunci ini tidak boleh memanggil model itu.
404model_not_foundTidak ada model dengan ID itu. ID ditulis huruf kecil.
422invalid_requestBody-nya tidak benar, atau panggilannya terlalu panjang. param menyebut field-nya.
429plan_limit_reachedPermintaan paket periode ini sudah habis, dan saldomu tidak cukup untuk panggilan ini.
429rate_limit_exceededBatas per detik, per menit, atau harian kuncimu.
429model_busyTerlalu banyak panggilan sekaligus. Tunggu, lalu kirim lagi.
502model_unavailableModel tidak bisa menjawab. Coba lagi dengan jeda bertahap.

Setiap 429 membawa Retry-After (detik) dan retry-after-ms (milidetik). Perlakukan kode 429 lain dengan cara yang sama.

Contoh

Python

Python
import os
import requests

API = "https://ai.zeiko.biz.id/v1"
KEY = os.environ["ZEIKO_API_KEY"]

def decide(state, questions):
    r = requests.post(
        API + "/decisions",
        headers={"Authorization": "Bearer " + KEY},
        json={"model": "pranata-v1", "state": state, "questions": questions},
        timeout=30,
    )
    if r.status_code == 429:
        raise RuntimeError("busy, retry in %s s" % r.headers.get("Retry-After"))
    r.raise_for_status()
    return r.json()["answers"]

answers = decide(
    "Can someone call me back today? The heating is off and it is freezing.",
    {
        "urgency": {
            "type": "score",
            "instructions": "How urgent is this message?",
            "criteria": ["Not urgent", "Low", "Medium", "High", "Drop everything"],
        },
        "team": {
            "type": "choice",
            "instructions": "Which team should take this message?",
            "criteria": {
                "repairs": "Something is broken",
                "accounts": "Questions about money",
                "other": None,
            },
        },
    },
)
print(answers["urgency"]["score"], answers["team"]["choice"])

JavaScript (Node 18 atau lebih baru)

JavaScript
const res = await fetch("https://ai.zeiko.biz.id/v1/decisions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.ZEIKO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "pranata-v1",
    state: "Can someone call me back today? The heating is off and it is freezing.",
    questions: {
      needs_reply: { type: "noul", instructions: "Does this message need a reply today?" },
    },
  }),
});
if (!res.ok) {
  const err = await res.json().catch(() => null);
  throw new Error(res.status + " " + (err?.error?.code ?? "") + ": " + (err?.error?.message ?? ""));
}
const { answers, usage } = await res.json();
console.log(answers.needs_reply.noul, usage.input_tokens);
