File & folder

Semua yang bisa kamu lakukan dengan file di Drive, tombol demi tombol. Baru pakai Drive? Mulai dari Dasar Drive.

Di halaman ini

  • Membuat folder dan file

Membuat folder dan file

Tekan Baru di folder yang kamu mau:

  • Folder baru membuat folder kosong (namanya awalnya Folder tanpa judul; ketik namanya).
  • Upload file dan Upload folder memilih dari perangkatmu. Folder ikut membawa folder-folder di dalamnya.
  • Dokumen, Spreadsheet, dan File teks membuka file kosong di editornya. Saat kamu simpan, file masuk ke folder yang sedang dibuka. Lihat Dokumen, spreadsheet & teks.

Di komputer kamu juga bisa menyeret file dari desktop ke halaman: Drive menyebutkan ke mana file itu masuk (Lepaskan untuk upload ke …).

Panel upload

Selama file naik, panel di bawah menampilkan setiap file dengan kecepatan dan sisa waktunya.

TulisannyaArtinya
MenungguMulai begitu salah satu file di depannya selesai. Beberapa file naik bersamaan.
Mencoba lagi…Koneksi sempat putus. Drive mencoba lagi sendiri.
Menyelesaikan…Semua sudah naik; Drive sedang menyatukan file-nya.
DijedaKamu menekan Jeda. Lanjut meneruskan dari situ.
Gagal / Dibatalkan / DilewatiFile tidak naik. Bersihkan menghapus baris yang sudah selesai dari panel.
  • Halaman tertutup di tengah jalan? Saat Drive dibuka lagi, Drive menawarkan melanjutkan dari titik terakhir: Lanjut atau Mulai ulang.
  • Namanya sudah ada? Pilih Ganti, Simpan keduanya, atau Lewati; centang Terapkan ke semua supaya cukup sekali untuk semua file.
  • Ruang habis? Upload berhenti dan menawarkan Tambah ruang. Lihat Paket Drive.

Tampilan dan urutan

Ganti antara Tampilan grid (gambar kecil) dan Tampilan daftar (baris dengan tanggal diubah dan ukuran). Urutkan menurut Nama, Tanggal diubah, Ukuran, atau Jenis. Folder yang panjang menampilkan file-file pertama dan tombol Muat lagi.

Memilih beberapa

  • Komputer: klik file untuk memilihnya, Ctrl-klik (⌘ di Mac) untuk menambah atau mengurangi satu, Shift-klik untuk memilih semua yang ada di antaranya. Ctrl+A memilih seluruh folder.
  • HP: tekan lama satu file, lalu ketuk file lainnya.

Bar di atas menyebutkan berapa yang dipilih dan menawarkan yang bisa untuk semuanya: unduh (beberapa file jadi satu arsip), bagikan, pindahkan, beri bintang, pindahkan ke Sampah. Batal pilih (atau Esc) melepasnya.

Memindah dan menyalin

  • Pindahkan ke… membuka folder-foldermu: masuk ke folder tujuan lalu tekan Pindahkan ke sini.
  • Buat salinan menaruh salinannya di sebelah aslinya.
  • Atau pakai keyboard: Ctrl+C (salin) atau Ctrl+X (potong), buka folder tujuan, lalu Ctrl+V.

Setiap tindakan juga punya Urungkan sebentar di pesan yang muncul sesudahnya.

Menu file

Klik kanan file, atau tekan ⋮-nya, untuk semua yang bisa dilakukan dengannya. Yang muncul tergantung jenis file:

MenuGunanya
Buka / PratinjauMembuka folder, atau menampilkan file.
UnduhMenyimpannya ke perangkatmu.
BagikanMembuat link. Lihat Berbagi & unduhan.
Ganti nama, Buat salinan, Pindahkan ke…Seperti di atas.
Edit foto, Edit video, Alat PDF, Jadikan PDF, Edit dokumen, Edit spreadsheet, Edit teks, Lihat isi ZIPMembuka file di editornya. Lihat Alat & editor.
Beri bintang / Hapus bintangMemasukkannya ke Berbintang, atau mengeluarkannya.

Pindahkan ke SampahMenghapusnya, masih bisa dikembalikan (di bawah).

Pratinjau

Foto, video, audio, PDF, teks dan kode, serta dokumen Word terbuka di pratinjau. Pakai tanda panah (atau ← →) untuk file sebelum atau sesudahnya, dan Esc untuk menutup. Edit di pratinjau membuka editor file itu. Untuk jenis file lain, pratinjaunya bilang belum tersedia; unduh saja filenya.

Pintasan keyboard

TombolGunanya
EnterMembuka file atau folder yang dipilih
F2Ganti namanya
Delete atau BackspaceMemindahkan pilihan ke Sampah
Ctrl+AMemilih semua isi folder
Ctrl+C, Ctrl+X, Ctrl+VSalin, potong, tempel
Tombol panahBerpindah antar file
EscMelepas pilihan, menutup pratinjau atau menu

Di Mac, ⌘ berlaku di tempat yang tertulis Ctrl.

Sampah lebih detail

  • Pindahkan ke Sampah mengeluarkan file dari foldernya; file itu masih memakai ruangmu sampai dihapus permanen.
  • Di Sampah, Pulihkan mengembalikan file ke tempat asalnya, dan Hapus permanen langsung menghapusnya. Ini tidak bisa dibatalkan.
  • Kosongkan Sampah menghapus semua isinya untuk selamanya. Sampah menyebutkan berapa hari file disimpan di sana sebelum terhapus sendiri.
