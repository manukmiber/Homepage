Tanya jawab Drive

Ada yang tidak berjalan seperti yang kamu kira? Cari pesan yang kamu lihat, atau pertanyaanmu.

Di halaman ini

  • Masuk
  • Upload
  • File dan link
  • Ruang dan paket
  • Editor
  • Di HP

Masuk

Drive terus menyuruhku masuk.

Drive mengikuti Akun Zeiko-mu. Masuk di halaman akunmu, konfirmasi email kalau diminta, lalu buka Drive lagi. Di jendela pribadi (incognito), masuk juga di sana.

Drive terbuka sebagai orang lain.

Drive menampilkan siapa pun yang sedang masuk ke Akun Zeiko di browser ini. Keluar di halaman akunmu lalu masuk sebagai dirimu.

“Sesi kamu sudah habis. Silakan masuk lagi.”

Kamu keluar di tempat lain, atau sudah lama sekali. Masuk lagi; isi Drive-mu tidak berubah.

Upload

Upload lama sekali bertuliskan Menunggu.

Hanya beberapa file yang naik bersamaan; file itu mulai saat salah satu di depannya selesai. File besar di depannya butuh waktu.

Upload berhenti waktu halaman kututup.

Buka Drive lagi di perangkat yang sama: Drive menawarkan melanjutkan dari titik terakhir (Lanjut).

“Koneksi terputus. Kami akan coba lagi otomatis.”

Upload jalan lagi sendiri begitu koneksi kembali.

Aku sama sekali tidak bisa upload.

Upload butuh paket dengan ruang kosong. Cek meteran ruang, atau buka Paket.

File dan link

File bertuliskan Sedang dipindai dan tidak bisa dibagikan.

Tunggu beberapa detik: file bisa dibagikan setelah Aman. Lihat pemindaian keamanan.

File bertuliskan Ditolak (berbahaya).

File itu cocok dengan sesuatu yang berbahaya, jadi tidak bisa diunduh atau dibagikan. Kalau menurutmu itu keliru, hubungi kami lewat kontak di beranda.

Ada yang bilang link-ku tidak bisa dibuka.

Halaman yang dia lihat menyebutkan alasannya: sudah berakhir, mencapai batas unduhan, dimatikan, atau butuh sandi. Buka Dibagikan untuk mengubahnya atau membuat link baru.

Aku tidak sengaja menghapus sesuatu.

Buka Sampah lalu tekan Pulihkan, selama Sampah belum dikosongkan.

Ruang dan paket

Ruangku penuh.

Kosongkan Sampah dulu (isinya tetap terhitung), hapus yang tidak perlu, atau tekan Tambah ruang. Lihat Paket Drive.

Apa yang terjadi kalau paketku habis?

Itu dijelaskan di Paket Drive, bersama cara memperpanjang dan naik atau turun paket.

Editor

“File terlalu besar untuk diedit di browser.”

Setiap editor punya batas ukuran supaya memori HP tidak habis; pesannya menyebutkan batasnya. Untuk file yang sangat besar, unduh lalu pakai aplikasi di komputermu.

Foto HEIC-ku tidak bisa dibuka.

Hanya sebagian browser yang bisa membuka HEIC. Coba di Safari, atau ubah dulu ke JPEG.

Editor video hanya menawarkan Cepat.

Browser ini belum bisa meng-encode video. Cara Cepat tetap bisa memotong dan menggabung tanpa menurunkan kualitas; cara Tepat butuh browser yang lebih baru.

File teks katanya bukan UTF-8.

Editor menolak membukanya supaya hurufnya tidak rusak. Buka di aplikasi komputer yang bisa mengubah encoding-nya ke UTF-8.

Teks di formulir PDF tidak mau tersimpan.

Formulir PDF hanya bisa diisi huruf Latin. Untuk aksara lain, taruh sebagai Teks di Isi & TTD.

Di HP

Bisa pakai Drive di HP?

Bisa, di browser HP: semua yang ada di sini jalan di sana, termasuk editornya. Tekan lama satu file untuk memilih beberapa.

Ada aplikasi yang perlu dipasang?

Drive jalan di browser; tidak ada yang perlu dipasang.
