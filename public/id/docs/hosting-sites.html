Online-kan situsmu

Masuk ke cPanel, lalu pasang WordPress, unggah file-mu sendiri, atau jalankan aplikasi. Kalau pakai domain sendiri, arahkan dulu ke sini (Sambungkan domain) supaya hasilnya bisa kamu lihat di sana; alamat di bawah zeiko.biz.id sudah langsung siap.

Di halaman ini

  • Masuk ke cPanel
  • WordPress sekali klik
  • Unggah situsmu sendiri
  • Basis data
  • Aplikasi Node.js
  • Aplikasi Python
  • Aplikasi Ruby
  • SSH dan Terminal
  • Email di domainmu

Masuk ke cPanel

Buka alamat cPanel dari email sambutanmu dan masuk dengan username dan password-mu. Kalau halamannya tidak mau terbuka setelah beberapa kali salah password, koneksimu sedang diblokir sementara: tulis ke admin@zeiko.biz.id dengan alamat IP-mu dan kami buka.

WordPress sekali klik

  1. Buka SoftaculousDi cPanel, buka Softaculous Apps Installer lalu pilih WordPress.
  2. Tekan InstallPilih https:// dan domainmu, lalu kosongkan In Directory supaya situsnya terbuka langsung di domain itu.
  3. Beri namaIsi nama situs, juga username, password dan email WordPress yang akan kamu pakai untuk masuk. Catat semuanya.
  4. InstallTekan Install dan tunggu sebentar. Softaculous menampilkan tautan untuk masuk ke WordPress.

Softaculous membuatkan basis data situsnya untukmu, dan memasang aplikasi lain dengan cara yang sama.

Unggah situsmu sendiri

File domain utamamu masuk ke folder public_html; tiap domain yang kamu tambahkan memakai folder yang kamu pilih untuknya. Halaman yang terbuka pertama adalah index.html atau index.php.

  • File Manager: buka public_html, tekan Upload, lalu unggah file-mu, atau satu ZIP berisi semuanya; lalu klik kanan ZIP itu dan pilih Extract.
  • FTP: FTP Accounts di cPanel membuat akun untuk aplikasi FTP seperti FileZilla. Sambungkan ke domainmu, atau alamat IP di email sambutanmu, di port 21.
  • Git: clone repository-mu lewat SSH ke folder itu.

Basis data

  1. Buat basis dataDi cPanel, buka MySQL Databases dan buat satu. Nama lengkapnya diawali username cPanel-mu, misalnya username_toko.
  2. Buat userDi halaman yang sama, tambahkan user dengan password yang kuat.
  3. Hubungkan user ke basis dataDi Add User To Database, pilih keduanya, tekan Add, lalu centang ALL PRIVILEGES.
  4. Masukkan ke pengaturan situsmuHost localhost, nama lengkap basis data, nama lengkap user, dan password-nya.

Untuk memasukkan basis data yang sudah kamu punya, buka phpMyAdmin, pilih basis datanya di sebelah kiri, lalu pakai Import dengan file .sql-mu.

Aplikasi Node.js

  1. Unggah kodenyaKe folder tersendiri di luar public_html, misalnya myapp, tanpa node_modules.
  2. Buat aplikasinyaDi cPanel, buka Setup Node.js App lalu tekan Create Application. Pilih versi Node.js, isi Application root dengan foldermu, Application URL dengan domain tempat aplikasi itu dibuka, dan Application startup file dengan file utamamu, misalnya app.js. Tekan Create.
  3. Pasang paketnyaTekan Run NPM Install: ia membaca package.json-mu.
  4. Restart tiap ada perubahanTekan Restart di halaman aplikasinya setiap kali kamu mengunggah kode baru.

Buat aplikasimu listen di process.env.PORT; aplikasinya dijalankan untukmu.

Aplikasi Python

  1. Buat aplikasinyaDi cPanel, buka Setup Python App lalu tekan Create Application. Pilih versi Python, folder Application root dan Application URL, biarkan startup file tetap passenger_wsgi.py, lalu tekan Create.
  2. Unggah kodenyaKe folder itu. passenger_wsgi.py menyerahkan aplikasimu sebagai application: untuk Flask, from app import app as application; untuk Django, application dari wsgi.py proyekmu.
  3. Pasang paketnyaTambahkan requirements.txt di Configuration files lalu tekan Run Pip Install. Atau, di Terminal, jalankan perintah yang tampil di atas halaman aplikasinya, lalu pip install -r requirements.txt.
  4. Restart tiap ada perubahanTekan Restart.

Aplikasi Ruby

  1. Buat aplikasinyaDi cPanel, buka Setup Ruby App, pilih versi Ruby, folder Application root dan Application URL, lalu buat.
  2. Unggah kodenyaKe folder itu, dengan config.ru yang menjalankan aplikasimu. Aplikasi Rails dan Sinatra sudah punya.
  3. Pasang gem-nyaDi Terminal, jalankan perintah yang tampil di halaman aplikasinya, lalu bundle install.
  4. Restart tiap ada perubahanTekan Restart.

SSH dan Terminal

Terminal di cPanel membuka shell di browser-mu. Untuk tersambung dari komputermu sendiri, buka SSH Access, lalu Manage SSH Keys: impor public key-mu dan beri izin. Lalu sambungkan dengan username cPanel-mu ke domainmu, atau alamat IP di email sambutanmu, di port SSH yang tertulis di sana.

Shell-nya jailed: hanya melihat file-mu sendiri, bukan milik orang lain. git, npm, pip dan bundle bisa dipakai di sana.

Email di domainmu

Di cPanel, buka Email Accounts lalu tekan Create untuk membuat alamat seperti kamu@domainmu.com. Baca lewat webmail di domainmu.com/webmail, atau di aplikasi email apa pun dengan pengaturan yang ditunjukkan Connect Devices di samping alamatnya. Email jalan begitu domainmu memakai cara 1.
