# Surface brief: the website and its account area

Scope: the homepage (Persuade, both languages) as a full desktop; /models, /drive, the docs and 404
(Read) and the account pages (Operate) as maximised program windows in an ordinary scrolling layout.
Audience, job, proof and constraints: PRODUCT.md. The owner pinned the era (Windows 95) and chose: a
full desktop on the homepage only, and a dark appearance scheme kept beside the standard one.

## Direction contract

THESIS: The site is a Windows 95 desktop where Zeiko's products are programs you open and run. It
refuses the AI-API landing it was: gradient headline, glass pill nav, eyebrow chips, rows of equal cards.

OWN-WORLD: Teal desktop; 3D-face grey chrome with two-pixel bevels (white and light grey up, mid grey
and black down); solid navy title bars with white bold pixel lettering; white sunken wells for documents
and fields; navy segmented blocks for every probability, meter and progress; pale-yellow tooltips. Pixel
face for chrome and display, an Arial-metric face for reading, monospace only for code and IDs. Night
scheme: dark teal desktop, charcoal chrome, the same bevel logic.

STORY: A visitor sees Pranata V1 already running as a program, answering three questions with segmented
bars, understands "a probability for every option, from $1", and either creates an account or asks it a
question live. The Start menu and desktop icons lead to Drive, the roleplay models, prices and docs.

FIRST VIEWPORT: Full-bleed teal desktop. Desktop icons in a column at the left (Pranata V1, Try it,
Zeiko Drive, Roleplay, Pricing, Models, Docs, Account). The Pranata V1 window to their right, about
three fifths of the width: title bar, menu bar, the name set large in the pixel face, the one-line
claim, the example answers as segmented bars in a sunken well, then Create an account (default button,
heavy border) and Try it free. Taskbar fixed at the bottom: Start with the Zeiko mark, one button per
open window, a tray with EN|ID, the appearance switch and the clock.

FORM: owner-pinned Windows 95, outside the rolled list (the roll assigned candidate 6, Primbon,
overridden by the owner); seed:14e76f708d54f68c. Signature: probability bars fill block by block,
stepped, when an answer lands; windows minimise to the taskbar and come back from it.
